Basic Calculator – .NET MAUI
A simple calculator built with .NET MAUI. This project demonstrates how to create a cross-platform (iOS, Android, Windows, Mac Catalyst) app with basic arithmetic functions.

Features
Addition, Subtraction, Multiplication, and Division
Clear and Reset Functions
Simple UI for demonstration and testing
Requirements
.NET 7.0 SDK (or the version specified in the .csproj)
Visual Studio 2022 with the .NET Multi-platform App UI development workload installed
This includes the workloads for Android, iOS, and Windows (optional: Mac Catalyst support on macOS)
Getting Started
Clone the repository (or download the zip)

git clone git@github.com:ldl7/ldl7--IS331-midterm.git 
If you downloaded the zip, just unzip it into your chosen directory.

Open the solution in Visual Studio 2022

Double-click the .sln file (or open it from Visual Studio’s “Open a project or solution” menu).
Restore NuGet packages (Visual Studio should do this automatically, but you can also do it manually: right-click the solution, choose Restore NuGet Packages).

Set your startup project (if needed)

In Visual Studio’s Solution Explorer, right-click the project and choose Set as Startup Project.
Select a target platform and Run

At the top of Visual Studio, use the dropdown to choose Windows Machine, Android Emulator, or iOS Simulator (on macOS), then click the Run button.
How to Use
Launch the app on your chosen platform.
Enter numbers and tap the operation buttons (+, -, ×, ÷).
Tap = to compute the result.
Use AC to clear the current expression and start fresh.
